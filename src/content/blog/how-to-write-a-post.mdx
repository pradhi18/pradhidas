## Making a new post

1. Add a file to `src/content/blog/`, e.g. `my-new-post.md`. The file name becomes the URL: `/blog/my-new-post`.
2. Copy the front matter (the block between the `---` lines) from this file and change it.
3. Write in Markdown below it. Use `.mdx` instead of `.md` if you want the extras below (notes and captioned photos).
4. Commit and push. The site rebuilds itself on GitHub in about a minute.

## Text

Normal paragraphs, **bold**, *italic*, [links](https://github.com/pradhi18) and `inline code` all work.

> A quote turns into a handwritten note.

## Photos

In plain Markdown, an image gets taped onto the page:

![Hole-punch flowers joined by a vine](../../assets/notebook/vine-strip.jpg)

In MDX, `<Photo>` adds a handwritten caption:

<Photo src={dahlia} alt="A dahlia drawn around a punched hole, with pebble patterns" caption="a dahlia that took a whole meeting" tilt={1.4} tape="var(--lilac)" />

Put your own images in a folder next to the post (e.g. `src/content/blog/images/`) and import or link them the same way.

## Cover image

Add `cover: ./images/my-cover.jpg` and `coverAlt: "what's in it"` to the front matter for a big taped photo at the top.
